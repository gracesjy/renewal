## 개요

최초로 자율주행 자동차 관련에 입문은 ESP32 기반 micro-ROS 였었다.  대략 10만원 가량의 ESP32 가 탑재된 자율주행 전용보드를 가지고 했었다.   ESP32 에 대해서도 이때 처음으로 접했던 것 같다.

![2026-08-06-120704.png](/assets/images/2026-08-06-120704.png)

이 보드에는 엔코더 모터부터 모든 것이 담겨져 있었지만, 추천하는 Lidar 가 달라서 Firmware 를 직접 만들어야 했었다.  물론 AI 가 없었다면 하지 못했겠지만 AI 가 있고 보드 회사에서 주는 ESP-IDF 환경을 참조해서 비교적 손쉽게 할 수 있었다.

그 이후에 일반적인 ESP32 개발보드로 만들 생각을 해서 시작했었던 것 같다.

## ESP32 개발보드 (ESP32 S3 WROOM1 Devkit C1, 44핀)

## 최초의 PCB 도전
나의 블로그에 JLCPCB 담당자가 답글을 올린 것을 보고, PCB 제작은 비쌀 것으로 생각했었다.  그러나, 가격이 스타벅스 커피값 정도였기 때문에 시도한 것 같다.  만능기판 가격이 더 비싸다.  그 이유는 JLCPCB 는 5장이 기본이지만 배송비 포함해도 $3.1 에 불과 했기 때문이다.

### 44핀 헤더핀의 부재
EasyEDA 를 처음 사용하게 되었고, ESP32 개발보드는 44핀이었다. 22핀 헤더핀이 필요했었다. 그러나, 그에 맞는 부품을 EasyEDA 에서 찾을 수가 없어서 10핀, 10핀, 2핀을 합쳐서 고정했고 이것 때문에 JLCPCB 담당자와 채팅을 했지만 2.54mm 를 맞춘다면 문제가 없다는 답변을 받았다.

## 완성된 모습

우려한 것보다는 어렵지 않았다. Firmware 는 GPIO 번호만 수정해서 재활용했고, 다만 범용 모터드라이버 보드와 인터페이스로 기존 소스를 바꾼 것이 특별했다.  이 부분은 의외로 보정이 필요했던 것 같다.

## 아키텍처
ESP32 는 Dual Core 이고 N16R8 의 메모리 및 저장 공간을 반드시 가지는 개발 보드를 구매해야 했다.  또한 ROS2 기존에서 3개의 publish, 3개의 subscribe 만 가능하다.  따라서 이 이상은 무리다. 다행히 Lidar, MPU6050 등은 publish 가 가능했고 부하를 고려해서 Task 를 적절히 Core 에 배정했다.

![2026-08-06-122646.png](/assets/images/2026-08-06-122646.png)

## 라즈베리파이 또는 PC 와 연동
ESP32 칩은 기본적으로 Wifi, Bluetooth (BLE) 를 제공하면서, micro-ROS 를 지원한다.  micro-ROS 는 micro-ROS agent 가 필요하며 실질적으로 ESP32 는 Serialized 된 패킷을 시리얼 또는 Wifi 로 전달하고 micro-ROS agent 가 이를 ROS2 로 Deserialize 한다. 

그래도 역할 분담, 분산 환경의 ROS 취지에 맞다고 생각한다. 무엇보다 ESP32 는 Network 이 되기 때문이다.  다만, ESP-IDF 환경으로 개발해야 했기 때문에 더 아기자기하고 재미 있지 않았나 싶다.
